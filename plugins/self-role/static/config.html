Leave empty for no limit. 1 makes it a “pick one” menu — choosing a role swaps out the previous one (great for colours, regions, pronouns).
Who can use it
Anyone, by default. Require a role (e.g. colour roles only for “Member”) or a minimum account age to keep brand-new accounts out.
Take the role back after a while
For temporary roles — event access, 24-hour pings. Off by default.
Log changes to a channel
Post a line like “@member gained Red” to a webhook each time someone uses this.
